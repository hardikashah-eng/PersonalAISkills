# Welcome example

## kenji-first-week: a manager welcomes a new engineer

Kenji (fictional) joins the Platform team. `note.json` holds the personal
note (why the team is glad, the shape of the week, his buddy), a team-channel
introduction with only what Kenji agreed to share (`consent`), a quote, and a
P.S. `card.png` is the printable card; `outputs.txt` shows the Slack DM and
the channel post.
