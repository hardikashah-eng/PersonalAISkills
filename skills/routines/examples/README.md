# Routines example

## team-lead: an engineering manager's weekly rhythm

- `routines.json`: the answers to setup: who, time zone, team, sources,
  channels, growth log (a Google Sheet), the standup, and which routines.
- `plan.txt`: what `make_routines.py` shows the user before anything is created.
- `routines-plan.json`: the four routines to create, each with a name, a cron
  schedule in the user's time zone, and a standalone prompt with the approval
  and privacy rules built in. The monthly reconnect is listed in the config
  but turned off.
