# Skills, grouped

Every skill lives directly in this folder, the standard plugin layout that
Claude Code, claude.ai and the plugin directory read. This index groups them.

## Personal

| Skill | For |
|---|---|
| [thankyou](thankyou/SKILL.md) | One-of-one thank-you notes for any occasion (also `--team`, `--org`, `--family`) |
| [reconnect](reconnect/SKILL.md) | No-guilt check-ins with people you've drifted from |
| [grateful](grateful/SKILL.md) | A seasonal gratitude list |
| [comfort](comfort/SKILL.md) | Steady, kind messages for hard times |
| [story-keeper](story-keeper/SKILL.md) | A family keepsake of an elder's stories, photos and voice |

## Shared

ThankYou's `scripts/` (safety check, card renderer, share links, card image,
pencil sketch) and its `references/` (quotes, language, safety, delivery,
sketches, photos, relationships and culture, fun facts, light moments) are
used by every skill.
