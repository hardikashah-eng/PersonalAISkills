# Choosing the language

## Decide from evidence, in this order

1. **The user says so** ("write it in Gujarati", "she only reads Spanish").
2. **How the user writes to you.** If the user's request is in a non-English
   language, they are likely more at home in it — write the note in that
   language (and offer an English version).
3. **How the user and recipient write to each other** (from connectors):
   - All in one language → use that language.
   - Mixed (code-switching, e.g. Hinglish, Spanglish, greetings in one language
     and work talk in another) → bilingual touch (below).
4. **Default:** the language of the user's request.

Never infer language from a name, surname, location, or appearance. If the
evidence is thin and it matters, ask one question:
"Would you like this in English, or in a language you two share?"

## Bilingual touch patterns

Use when the relationship is mixed-language or the user is a native speaker of
another language writing to an English-speaking context:

- **Greeting + closing** in the native language, body in the shared language.
  "Priya ji," … "Dil se shukriya," (from the heart, thank you)
- **Quote** in the native language with an English translation underneath.
- **One key line** in the native language — the line about what changed —
  so the most heartfelt sentence is in the heart language.

## Writing well in other languages

- Use the right register: formal "you" where expected (Sie, usted, vous, आप,
  您) for elders, teachers, senior colleagues; informal for friends.
- Use natural, culturally fitting expressions of thanks rather than literal
  translations of English idioms ("words can't express" does not translate well).
- Respect script and direction: Devanagari, Tamil, CJK fonts render via the
  card's system font stack; set `"direction": "rtl"` for Arabic, Hebrew, Urdu, Persian.
- Check honorific conventions: "ji" (Hindi), "-san"/"-sensei" (Japanese),
  "Sir/Ma'am" for teachers in Indian English, etc.
- If not confident in a language, keep the native portion short and correct
  (greeting, closing, quote) rather than writing a full note with errors, and say so.
