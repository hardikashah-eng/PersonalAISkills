# Handwriting fonts

Embedded by `scripts/render_card.py` in handwritten-style cards. Only the
subsets a card's text needs are embedded.

| File | Font | Covers | Licence |
|---|---|---|---|
| `caveat-latin-500-normal.woff2`, `caveat-latin-700-normal.woff2` | Caveat (The Caveat Project Authors) | Latin | SIL OFL 1.1, `OFL-Caveat.txt` |
| `caveat-latin-ext-500-normal.woff2` | Caveat | Latin Extended | SIL OFL 1.1 |
| `caveat-cyrillic-500-normal.woff2` | Caveat | Cyrillic | SIL OFL 1.1 |
| `kalam-devanagari-400-normal.woff2` | Kalam (Indian Type Foundry) | Devanagari | SIL OFL 1.1, `OFL-Kalam.txt` |

Source: the `@fontsource/caveat` and `@fontsource/kalam` packages, unmodified.
