# Feedback example

## dami-design-reviews: to a direct report

Dami (fictional) is a senior engineer whose design reviews put risks after a
long demo. `note.json` holds the `feedback` parts, six 1:1 talking points, and
a short written recap sent after the conversation.

`outputs.txt` shows the email recap, the two growth-log entries (the
improvement opportunity, and the strength alongside it), and the summary
prepared for the next 1:1 (`../references/growth-log.md`). `growth-log.json`
holds the same two entries (in the user's file, each is one line of JSON Lines).
