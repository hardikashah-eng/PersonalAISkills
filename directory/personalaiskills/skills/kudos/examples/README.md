# Kudos example

## bea-retry-fix: one fix, four versions

Bea (fictional) fixed a retry storm in PR #482. `note.json` holds:

- `body`: a direct message naming what she did, the difference, and the care behind it
- `channel_post`: the #kudos version for Slack
- `manager_note`: a note to her manager, so it counts at review time
- `public_post`: a LinkedIn post in public terms, with no PR number, no
  internal detail, and Bea's consent recorded (checked with the public-post
  section of `../../thankyou/references/safety-checklist.md`)

`outputs.txt` shows all four, formatted for their channels as in
`../../thankyou/references/channel-formats.md`.
